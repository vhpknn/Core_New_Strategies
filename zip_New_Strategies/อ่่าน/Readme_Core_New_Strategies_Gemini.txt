ที่ Claude ส่งมาคือ "คู่มือจำลองการทำงานตั้งแต่ต้นจนจบ" (Workflow) เพื่อให้คุณเห็นภาพว่า เวลาจะสร้างบอทตัวใหม่ (เช่น EA_SMC) จากแม่แบบ template-v0.1.1.zip ต้องทำอะไรตามลำดับบ้างครับ
แบ่งการทำงานออกเป็น 3 ช่วงหลักๆ (3 เฟส) แบบเข้าใจง่ายๆ ดังนี้ครับ:

เฟส 1: คุยสเปกกับ AI (ยังไม่ต้องเขียนโค้ด)

เหมือนการจ้างสถาปนิกออกแบบบ้านก่อนลงมือสร้างครับ
1. แตกไฟล์ซิป: แตกไฟล์ template-v0.1.1.zip ออกมาเป็นโฟลเดอร์ใหม่ (ตั้งชื่อรอไว้เลยก็ได้ เช่น EA_SMC)
2. สร้างชุดไฟล์ส่งให้ AI: รันคำสั่ง python tools\make_ai_bundle.py --job consult เพื่อรวบรวมคู่มือและโค้ดแม่แบบใส่ไฟล์เตรียมส่งให้ AI
3. เปิดแชตใหม่แล้วโยนไฟล์ให้ AI: นำข้อความจาก 00_START_PROMPT.txt พร้อมแนบไฟล์ 01_DOCS_BUNDLE.md และ 02_CODE_BUNDLE.txt ส่งให้ AI
4. ตอบคำถาม AI เรื่องระบบเทรด: AI จะถามรายละเอียดกลยุทธ์ของคุณทีละข้อ (เช่น เข้าออเดอร์ยังไง, ตั้ง SL/TP เท่าไหร่, กดปุ่ม OFF แล้วให้ทำอะไร) คุณก็ตอบตามไอเดียของคุณ
5. ได้พิมพ์เขียว (BLUEPRINT.md): พอคุยจบ AI จะสรุปแผนทั้งหมดให้ คุณก็นำข้อความนั้นไปแปะเก็บไว้ในไฟล์ docs/BLUEPRINT.md และ docs/SPEC_FORM.md

เฟส 2: ตั้งชื่อบอทและสร้างโปรเจกต์

พอได้แบบแปลนแล้ว ก็เริ่มขึ้นโครงสร้างบอทจริงครับ
1. รันคำสั่งตั้งชื่อบอท:cmd
python tools\init_strategy.py --name SMC --tag SMC --ordinal 3
Use code with caution.
(สคริปต์จะเปลี่ยนชื่อไฟล์ทั้งหมดจากคำว่า Template ให้กลายเป็น SMC และตั้งเลข Magic Number ให้โดยอัตโนมัติ)
2. ทดสอบ Compile: เปิดไฟล์ SMC_EA_TH.mq5 ใน MetaEditor กด F7 เช็กว่าผ่าน 0 errors 0 warnings
3. อัปโหลดขึ้น GitHub: สร้าง Repo ใหม่บน GitHub ชื่อ EA_SMC แล้วสั่ง git push เก็บขึ้นคลาวด์ไว้กันหาย

เฟส 3: สั่ง AI เขียนโค้ดทีละส่วน + ทดสอบ

เหมือนช่างก่อสร้างที่ทำทีละห้อง แล้วให้คุณตรวจรับงานครับ
1. สั่ง AI สร้างชุดไฟล์โค้ด: รันคำสั่ง python tools\make_ai_bundle.py --job build ส่งให้ AI
2. ตรวจแผนก่อนลงมือ: AI จะส่งรายชื่อไฟล์ที่จะแก้ไขมาให้ดูก่อน (ยังไม่ส่งโค้ด) พอคุณโอเคก็พิมพ์คำว่า "เริ่มงาน"
3. ก๊อปปี้โค้ดมาใส่ + Compile: AI จะส่งโค้ดมาให้ทีละชุด คุณก็นำมาวางในไฟล์ > กด F7 Compile เช็ก Error > รัน run_checks.bat > บันทึกลง Git ทำวนแบบนี้จนครบทุกฟังก์ชัน
4. นำไป Backtest / Demo: เอาไฟล์บอทที่เสร็จแล้วไปทดสอบใน MT5 และจดบันทึกผลลงในไฟล์ docs/work/TEST_MATRIX.md

กฎเหล็ก 3 ข้อที่ห้ามลืม (ป้องกันพัง)

• ห้ามรันคำสั่งตั้งชื่อ (init_strategy) ในโฟลเดอร์แม่แบบต้นฉบับ (Core_New_Strategies) ให้ทำในโฟลเดอร์ที่แตกไฟล์ซิปออกมาใหม่เท่านั้น
• ห้ามแก้โค้ดข้างในโฟลเดอร์ Core/ ให้แก้เฉพาะไฟล์ของกลยุทธ์ (เช่น SMC_Inputs.mqh, SMC_Strategy.mqh)
• ห้ามให้ AI แอบเขียนโค้ดก่อนคุณสั่ง ในช่วงปรึกษา (เฟส 1) ให้คุยจนจบสเปกก่อน ค่อยพิมพ์คำว่า "เริ่มงาน" ในเฟส 3 ครับ
หากพร้อมเริ่ม เฟส 1 (แตกไฟล์ซิปและรันคำสั่ง --job consult) เพื่อวางสเปกกลยุทธ์ SMC ตัวแรก แจ้งได้เลยครับ เดี๋ยวผมช่วยไกด์คำตอบแต่ละข้อใน SPEC_FORM.md ให้ครับ
